Basic Docker Commands
🔹 1. Check Docker Version
docker --version

👉 Shows installed Docker version

🔹 2. Pull an Image
docker pull nginx

👉 Downloads an image from Docker Hub

🔹 3. List Images
docker images

👉 Shows all downloaded images

🔹 4. Run a Container
docker run nginx

👉 Runs a container from an image

Run in background:
docker run -d nginx
Run with port mapping:
docker run -d -p 8080:80 nginx

👉 Access via: http://localhost:8080

🔹 5. List Running Containers
docker ps
Show all (including stopped):
docker ps -a
🔹 6. Stop a Container
docker stop <container_id>
🔹 7. Start a Container
docker start <container_id>
🔹 8. Remove a Container
docker rm <container_id>
🔹 9. Remove an Image
docker rmi <image_id>
🔹 10. Build a Docker Image
docker build -t myapp .

👉 Builds image from Dockerfile

🔹 11. View Logs
docker logs <container_id>
🔹 12. Execute Command Inside Container
docker exec -it <container_id> bash
🔹 13. Push Image to Docker Hub
docker push username/myapp
🔹 14. Login to Docker Hub
docker login
🔹 15. Remove All Stopped Containers
docker container prune

start vs run 

Here’s a clear and interview-friendly difference between docker run and docker start 👇

🐳 docker run vs docker start
🔹 1. docker run

👉 Creates + Starts a new container

docker run nginx
✅ What it does:
Pulls image (if not present)
Creates a new container
Starts the container

📌 Every time you run this → new container is created

🔹 2. docker start

👉 Starts an existing (stopped) container

docker start <container_id>
✅ What it does:
Starts a container that already exists
Does NOT create a new one
🔥 Key Difference
Feature	docker run	docker start
Creates container	✅ Yes	❌ No
Starts container	✅ Yes	✅ Yes
Works on new image	✅ Yes	❌ No
Works on stopped container	❌ No	✅ Yes
🧠 Simple Example
Step 1: Run container
docker run -d nginx

➡️ Creates + starts container

Step 2: Stop it
docker stop <container_id>
Step 3: Start again
docker start <container_id>

➡️ Reuses same container (no new one)

🎯 Easy Analogy
docker run → Install + Open app
docker start → Open already installed app
✅ Interview Answer (Short)

👉 “docker run creates and starts a new container from an image, while docker start is used to restart an existing stopped container.”
